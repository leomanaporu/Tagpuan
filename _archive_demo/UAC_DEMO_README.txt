WINDOWS UAC INFORMATION AND CONSENT DEMO

Windows User Account Control (UAC) is built into Windows. There are no separate
UAC files that website visitors need to download. To review its settings, open
Start and search for "Change User Account Control settings".

This ZIP contains only a browser-based consent prompt demonstration. Open
uac_demo.html in a browser to view it. The simulation is not a Windows security
prompt and cannot grant administrator access. It does not launch a terminal,
execute commands, or change system settings.
